# 9Proxy GB-трафик прокси — один шаблон на строку
#
# _ssid_ будет автоматически заменён на уникальный session ID
# для каждого профиля, чтобы каждый аккаунт получил свой IP.
#
# Формат: socks5://username:password@host:port
#
# Пример (9Proxy GB-traffic):
# socks5://malanda43_UAZs-country-US-ssid-_ssid_-sst-120:ff322@niceproxy.io:17521
#
# Параметры в юзернейме (9Proxy):
#   country-XX  — код страны (US, DE, RU и т.д.)
#   ssid-_ssid_ — session ID (заменяется автоматически)
#   sst-120     — время жизни сессии в минутах
#
# Также поддерживаются обычные прокси без _ssid_:
# socks5://user:pass@host:port
# http://user:pass@host:port
